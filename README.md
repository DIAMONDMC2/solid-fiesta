> **🎵 Powerful Telegram music bot for voice chats**

Feature-rich Telegram bot for playing music in voice chats. YouTube, Spotify, SoundCloud support with queue management and admin controls.

## ✨ Features

- 🎵 **Multi-Platform** - YouTube, Spotify, SoundCloud
- 🎙️ **Voice Chat** - High-quality audio streaming
- 📋 **Queue System** - Manage playlists
- 🔍 **Search** - Find songs easily
- ⏯️ **Controls** - Play, pause, skip, stop
- 👥 **Multi-User** - Works in multiple groups
- 🎨 **Rich UI** - Beautiful inline buttons
- 📊 **Stats** - Track plays and users

## 🚀 Installation

```bash
git clone https://github.com/DAXXTEAM/MUSICBOT.git
cd MUSICBOT
pip install -r requirements.txt
python main.py
```

## 📖 Commands

```
/play <song>   - Play song
/pause         - Pause playback
/resume        - Resume playback
/skip          - Skip current song
/queue         - Show queue
/volume <1-100> - Set volume
```
